# Issue tracker: GitHub

Issues and specs live in GitHub Issues for `burapa009/aia-bu`.
Use the `gh` CLI and infer the repository from the Git remote.

- Publish tickets as separate GitHub issues.
- Read issue bodies, comments, and labels before working.
- Apply or remove labels with `gh issue edit`.
- PRs are not a triage/request surface.
- Use GitHub native blocking dependencies when available.
- Otherwise record blockers as `Blocked by: #<number>`.
- A ticket is ready when every blocking issue is closed.
